# Krishna Kalwar — Portfolio

Personal portfolio for Krishna Kalwar, a BSc IT graduate interested in Application Support Engineering. It highlights his troubleshooting approach, technical toolkit, education, and two full-stack projects.

## Featured work

- **KnullVoid MultiGame Web Portal** — React, WebAssembly/Ruffle, Rust, Google MediaPipe, Three.js, and Cloudflare. Live at [knullvoidgames.pages.dev](https://knullvoidgames.pages.dev/).
- **FitSyn — AI Fitness Platform** — Next.js, TensorFlow MoveNet/PoseNet, OpenAI API, Firebase, and Recharts. Live at [fitsyn.vercel.app](https://fitsyn.vercel.app/).

## Built with

React, TypeScript, Vite, Three.js, Tailwind CSS v4, and custom responsive CSS.

## Run locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it locally with `npm run preview`.

## Deploy to Vercel

Import this repository into Vercel and keep the detected Vite settings: build command `npm run build`, output directory `dist`, and a supported Node.js runtime (20.19+ or 22.12+). No environment variables are required. The Vercel config adds baseline security headers. The downloadable resume is served from `public/Krishna_Kalwar_A.docx`.

## Personal details

The portfolio content and project links are maintained in `src/App.tsx`. Search and social metadata are in `index.html`, and visual styles are in `src/index.css`.
